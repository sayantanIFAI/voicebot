# Engineering backlog — 2026-10-31 (for the junior engineer)

Source: an outside technical assessment of this repository, checked line by line against the code at `main` on 2026-10-31. The assessment could not read the repository, so some of its "documented findings" were already fixed; those are listed in part A so nobody redoes them. Part B is the work, in order. **Do the rows in order within a priority; do not start P1 before every P0 acceptance test passes.** After each row: run the tests named in "Done when", commit, push, and write one line in `docs/CHANGES_*.md`.

Ground rules (all of them are already how this code works; do not break them):
1. The model only reads intent and slots. Every FACT said to a caller (price, doctor, day, time, serial, booking id) comes from deterministic code and the clinic database.
2. A fix must work in all three languages (bn, hi, en) and every department.
3. `main_pcm.py` is generated: edit `main.py`, then run `python tools/make_pcm_variant.py`.
4. Never `pkill -f` over ssh (it kills your own session); restart agents by pid.
5. A new behaviour gets a test first; the test must fail before the fix and pass after.
