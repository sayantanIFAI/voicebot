# Phone calls via Twilio

Call the Twilio number (+1 415 797 0932) -> Twilio answers -> streams the caller's audio to the agent on the pod -> the agent's
reply is played back on the same call. Written by sourav, 2026-10-21. Code: `agent/twilio_bridge.py`; tests: `tests/test_twilio_bridge.py`.

## How it fits
- `POST /twilio/voice` is Twilio's incoming-call webhook. It checks Twilio's `X-Twilio-Signature`, then answers with
  `<Connect><Stream url="wss://<host>/twilio/stream">` plus a short-lived per-call token.
- `WS /twilio/stream` carries 8 kHz mu-law audio. An adapter makes it look like the browser socket, so the existing
  `ws_audio` turn loop runs unchanged (same ASR, intent, tools, TTS). Replies are converted to 8 kHz mu-law; `mark`
  events replace the browser's `playback_done`; barge-in `stop_playback` becomes Twilio's `clear`.
- `GET /twilio/health` shows whether the bridge is configured (never prints the token).
- Registered only in `main_pcm.py` (generated by `tools/make_pcm_variant.py`); `main.py` and the browser path are untouched.

## Settings (pod environment or `.env`; never commit)
| Variable | Meaning |
|---|---|
| `TWILIO_AUTH_TOKEN` (or `AuthToken`) | Required. Without it the webhook answers 503 and refuses to run unprotected. |
| `TWILIO_PUBLIC_BASE_URL` | `https://<POD_ID>-8888.proxy.runpod.net` - the exact URL Twilio calls (used for the signature check). |
| `TWILIO_ALLOWED_CALLERS` | Optional comma-separated caller numbers (digits). Others are rejected. |
| `TWILIO_VALIDATE_SIGNATURE=0` | Testing only. |
| `TWILIO_BRIDGE=0` | Switch the bridge off. |

## Go-live checklist
1. Pod running with the PCM agent; put the token and `TWILIO_PUBLIC_BASE_URL` in the pod environment.
2. Add `deploy/gateway/twilio_location.conf` to the pod's nginx server block (exempts `/twilio/` from basic auth), then `bash /workspace/gateway/gateway.sh pcm`.
3. Check `https://<POD_ID>-8888.proxy.runpod.net/twilio/health`.
4. In Twilio: Phone Numbers -> the number -> Voice Configuration -> "A call comes in" = Webhook, `POST`,
   `https://<POD_ID>-8888.proxy.runpod.net/twilio/voice` (replaces the `hello-test` TwiML Bin).
5. Call the number. Logs show `Twilio call CA..` then the normal call log.
6. If RunPod's proxy will not pass WebSockets, expose the pod through a Cloudflare Tunnel and use that host as the base URL.
7. Rotate the Auth Token after testing and update the pod.

## Notes
- Expect roughly 0.3-0.6 s extra latency on the phone path versus the browser (not yet measured).
- Echo cancellation was tuned for browser audio; verify barge-in on a real call (`AEC_BARGE_IN`).
