# Changes of 2026-10-29 (owner-driven, from real calls)

Capacity changes are in [ADR 0005](adr/0005-capacity-round-2026-10-29.md). This page lists what a CALLER now experiences and where the code is. Everything is deterministic code or the clinic's own tables; the model still only reads intent and slots.

| Caller says / situation | What happens now | Code |
|---|---|---|
| A doctor was offered ("Dr. Sutapa Chatterjee, Dr. Rina Mitra…") and the caller names one in another script ("सुतापा चटर्जी") | The doctor is picked by the sound of the name (Bengali / Devanagari / spelling variants), the reply stays in the call's language, and the booking goes on. Naming the one offered doctor counts as the yes. The "are you asking about Dr. X?" check is not asked again for a name that picks an offered doctor. | `agent/doctor_search._choose_by_sound`, `main._names_offered_doctor` |
| "মাথায় ব্যথা" (a headache) | Asked once: "only a headache, or did you get hurt on the head?". Hurt goes to General Medicine, a plain headache to Neurology; then the usual "who sits, shall I book?" and a yes goes on to the booking. | `agent/head_pain.py`, `main._head_pain_turn` |
| Asked to pay by phone / UPI and the caller says they have a small or keypad phone, or cannot do it | "Then you will need to come to the clinic counter and pay there"; the booking goes on. A plain "no WhatsApp" still asks for another number. | `agent/whatsapp_cues.cannot_pay_online`, prompt `pay_at_counter` |
| "Which floor / room does the doctor sit in?" | "That will be told at the clinic counter" (the tables hold no floor). | `agent/where_doctor_sits.py` |
| A first name that is nobody's plus a shared surname ("রাজেশ্বরী দত্ত") | The first name the caller said is kept with the surname the model kept, so the clinic is asked about the whole name; no one doctor is answered for from the surname. The answer is "no doctor by that name, did you mean Dr. Rajarshi Dutta?". | `main._restore_said_given_name` |
| The surname alone ("দত্ত") with two doctors | Both doctors are named and the caller is asked which (Dr. Manas Dutta, Dr. Rajarshi Dutta; the new doctor's surname alias was missing). | `clinic-api/clinic_extras.EXTRA_ALIASES` |
| "Give me a moment, I will give the name" | Thanked, asked to call again, call closed. | `agent/call_later.py` |
| A slow clinic API during a booking | The duplicate-booking check is asked twice, then skipped; the booking is not ended. | `agent/tools_client.py`, `main.py` |

Also merged from other sessions today: Dr. Rajarshi Dutta (General Medicine, Mon-Fri 10-13 until the real hours are set), Neuro Medicine routing and a Psychiatry department, a confidently matched district / police station is accepted as a complete address, the audio consumer processes everything queued in one call, ingestion reads audio before the greeting and sheds new calls on slow turns.

## Switches (environment, `deploy/env.sh`)

| Variable | Default | Meaning |
|---|---|---|
| `AEC_MODE` | `full` | `full`: echo canceller on every call. `phone_light`: phone-line calls skip the canceller's maths (decision pending a SIP caller test). |
| `CLINIC_WORKERS` | `3` | Worker processes of the clinic API. `1` restores the single process. |
| `AVAILABILITY_PRELOAD_INTERVAL_S` / `AVAILABILITY_TTL_S` | `60` / `120` | Background availability refresh and how long an entry is used. |
| `SCHEDULE_CACHE_TTL_S` | `20` | Clinic API's weekly-schedule cache. |
| `OLLAMA_NUM_PARALLEL` | `8` | Ollama slots; one start-up request per slot warms the shared prompt. |
